# My12Steps

My run through Lorena A. Barba and Gilbert F. Forsyth's course [12 Steps to Navier–Stokes](https://github.com/barbagroup/CFDPython) (2018), in plain Python scripts (`12Steps/Steps/`), extended with Numba-accelerated solvers and an interactive fire simulation, `12Steps/FireSim.py`.

Run: `cd 12Steps && python FireSim.py` (written for Python 3.6; needs `numpy<1.24`, `numba`, `pygame`, `opencv-python` and `matplotlib`). Drag with the right mouse button to add heat, with the left to add fuel; `R` resets, `Esc` quits.
